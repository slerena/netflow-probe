Pandora FMS Netflow Probe — paquete para Windows (64 bits)
==========================================================

Aplicación ligera que captura el tráfico del propio equipo y lo exporta como
NetFlow v9 al colector de Pandora FMS.

Cómo usarlo
-----------
1. Abre "PandoraFMSNetflowProbe.exe". Windows pedirá permisos de administrador:
   son necesarios para cargar el driver de captura WinDivert.
2. En "Colector NetFlow (Pandora)" escribe la IP o el host del servidor
   Pandora FMS. El puerto por defecto es 9995.
3. Pulsa "Iniciar". La barra verde indica que está capturando y verás los
   contadores de paquetes, MB, flujos activos y exportados.
4. "Guardar configuración" escribe %USERPROFILE%\.netflow-probe.yaml.

WinDivert
---------
La captura la hace el driver WinDivert. WinDivert.dll y WinDivert64.sys deben
estar junto al .exe (ya vienen en este paquete). Requiere administrador.
WinDivert es dual LGPL-3.0 / GPL-2.0.

Agente y servicio (netflow-probe.exe)
-------------------------------------
El paquete incluye también el agente sin interfaz, que puede correr como
servicio de Windows (sin sesión de usuario):

  netflow-probe.exe -install -config "C:\ProgramData\Pandora\netflow-probe.yaml"
  netflow-probe.exe -uninstall

El fichero de configuración debe existir y tener al menos:
  collector: <ip-del-servidor-pandora>
  port: 9995

Notas
-----
- Windows de 64 bits (x86-64).
- La configuración se guarda en el perfil del usuario, no aquí.
